# Communication App

A simple PHP-based chat application for two users (person1 and person2).

## Setup

1. PUT ALL THE FILE IN FOLDER AND NAME IT "Communication App"
2. Import `sql/database.sql` into MySQL to create the database.
3. Update database credentials in `config/database.php` if needed.
4. Start Apache and MySQL in XAMPP.
5. Access `http://localhost/Communiction App/`

## Features

- User registration and login
- Real-time chat between two users
- Message history
- Secure authentication

- `index.php` - Landing page
- `login_form.php` - Login form

- `dashboard.php` - Chat dashboard
- `config/database.php` - Database configuration
- `css/style.css` - Styles
- `js/script.js` - JavaScript for chat functionality
